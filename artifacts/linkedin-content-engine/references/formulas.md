# Language Modes, Professionalism Dial, and F1–F8 Formulas

## Language modes

| Mode | Use |
|---|---|
| EN | Clean professional English for formal posts, international reach, and technical deep-dives. |
| MSA | Modern Standard Arabic for formal announcements and institutional news. |
| SA-Pro | White Saudi dialect: natural, polished, lightly dialectal. |
| SA-Casual | Warm Saudi dialect for celebrations and behind-the-scenes. |
| MIX | Arabic body with established English technical terms retained. |

In Arabic, keep English dev terms inline without transliteration, use Western digits, Arabic punctuation, and do not mix MSA with heavy dialect.

## Professionalism dial

- P5: Corporate/formal; 0–1 emoji; MSA or formal EN; no jokes.
- P4: Professional; 1–2 restrained emojis; confident and polished.
- P3: Professional-friendly default; 2–4 emojis; short punchy lines.
- P2: Casual-authentic; 3–6 emojis; dialect, humor, personal voice.
- P1: Community/fun; freely use emojis; celebrations only.

## Formulas

### F1 — Achievement / Milestone

Default P3–P4, MIX or EN, 2–3 emojis. Use achievement hook; honest context; 2–4 short journey lines; specific gratitude; forward-looking close; 3–5 hashtags.

### F2 — Advice / Educational

Default P3, MIX or SA-Pro, 2–4 emojis. Use a pain/payoff hook, promise, 3–7 numbered points, one deeper insight, one engagement question, and 3–5 hashtags. Propose a carousel when five or more list items are strong.

### F3 — Formal / Corporate Announcement

Default P5, MSA or formal EN, 0–1 emoji. State the news, add organization/role/significance context, mention Vision 2030 only if genuinely relevant, offer formal thanks, and finish with 3–4 institutional hashtags.

### F4 — Project Showcase / Devlog

Default P3, MIX, 2–4 emojis, always with media. State what it does, the problem, 3–5 technical lines, an honest limitation, feedback ask, then 4–5 hashtags.

### F5 — Story / Behind-the-Scenes

Default P2–P3, SA-Pro, 3–5 emojis. Open with tension, tell setup → struggle → turn → resolution in short lines, state the lesson, add a relatable close/question, then 3–4 hashtags.

### F6 — Community / Event Recap

Default P2–P3, SA-Pro or MIX, 4–6 emojis, with photos. Use an energy hook, details/highlights, specific shoutouts, what is next/how to join, then 4–5 community hashtags.

### F7 — Gratitude / Shoutout

Default P3, match the person’s language, 1–3 emojis. Name the person/team, specify what they did and how it mattered, thank/tag them, then 2–3 hashtags.

### F8 — Discussion Starter / Perspective

Default P3–P4, EN or MIX, 1–2 emojis. Lead with a defensible position, give 3–4 lines of reasoning, acknowledge the other side, ask a direct question, then 3–4 hashtags. Keep it constructive.
